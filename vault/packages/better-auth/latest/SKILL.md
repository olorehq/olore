# better-auth Documentation

Better Auth is a framework-agnostic, universal authentication and authorization framework for TypeScript. It provides a comprehensive set of features out of the box and includes a plugin ecosystem that simplifies adding advanced functionalities.

## When to use

Use this skill when the user asks about:
- Setting up authentication in TypeScript (email/password, OAuth, passkeys, magic links)
- Configuring social providers (Google, GitHub, Discord, Apple, and 30+ others)
- Session management, cookie configuration, and stateless sessions
- Database adapters (Prisma, Drizzle, MongoDB, PostgreSQL, MySQL, SQLite)
- Plugins: 2FA, organizations, admin, API keys, SSO, OIDC, JWT, bearer tokens
- Framework integrations: Next.js, Nuxt, SvelteKit, Astro, Hono, Express, and more
- Migrating from Auth.js, Auth0, Clerk, Supabase Auth, or WorkOS
