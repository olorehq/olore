# Brand Safety & Suitability

Meta provides brand suitability controls to place ads adjacent to suitable organic content on Facebook, Instagram, and Meta Audience Network.

## Available Tools

### Block Lists API
Stop ads from appearing with publishers you don't consider suitable:
```bash
POST /v25.0/act_{AD_ACCOUNT_ID}/publisher_block_lists
```

### Content Allow Lists API
Customize lists of brand-suitable videos for Facebook in-stream campaigns (via Meta Business Partners).

### Content Delivery Reports API
See where ads appeared and view impressions at the content level for transparency.

### Feed Verification API
Measure, verify, and understand the suitability of content near your ads.

### Partner-publisher Lists API
View publishers signed up for monetization that follow Meta's Partner Monetization Policies.

### Publisher Delivery Reports API
View impressions at the publisher level.

### Passback API
Partners share content risk labels and campaign performance data with Meta.

## Content Standards

Meta enforces Facebook Community Standards and Instagram Community Guidelines for all content and publishers.

## Setup Requirements

- Business Manager account
- Ad account with appropriate permissions
- App with Marketing API access
