# agentskills Documentation Structure

## Files

| File | Description |
|------|-------------|
| `contents/home.mdx` | Overview of Agent Skills format — a lightweight, open format for extending AI agent capabilities with specialized knowledge and workflows |
| `contents/specification.mdx` | Complete format specification for Agent Skills — SKILL.md structure, frontmatter fields, progressive disclosure loading strategy |
| `contents/clients.mdx` | Client showcase — agent products that support the Agent Skills format |
| `contents/skill-creation/quickstart.mdx` | Quickstart tutorial — create your first Agent Skill and see it work in a compatible agent |
| `contents/skill-creation/best-practices.mdx` | Best practices for skill creators — how to write well-scoped skills grounded in real expertise |
| `contents/skill-creation/evaluating-skills.mdx` | Evaluating skill output quality — how to test skills using eval-driven iteration and structured test cases |
| `contents/skill-creation/optimizing-descriptions.mdx` | Optimizing skill descriptions — how to improve the description field so a skill triggers reliably on relevant prompts |
| `contents/skill-creation/using-scripts.mdx` | Using scripts in skills — how to bundle and run shell commands and executable scripts within a skill |
| `contents/client-implementation/adding-skills-support.mdx` | How to add Agent Skills support to an AI agent or development tool — discovery, context loading, and progressive disclosure |
| `contents/CLAUDE.md` | Guidance for Claude Code when working in the agentskills repo — dev server, navigation, deployment notes |
| `contents/README.md` | Documentation site README — development setup and publishing instructions for the Mintlify site |
