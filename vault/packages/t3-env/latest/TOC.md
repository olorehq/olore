# t3-env Documentation Structure

## Files

| File | Description |
|------|-------------|
| `contents/core/page.mdx` | Framework-agnostic core package installation and setup with server/client env separation |
| `contents/customization/page.mdx` | Customization options including skipping validation, error handling, and extending presets |
| `contents/introduction/page.mdx` | Overview of T3 Env features: type-safe env vars, Standard Schema support, server/client separation |
| `contents/nextjs/page.mdx` | Next.js-specific integration using @t3-oss/env-nextjs with setup and usage examples |
| `contents/nuxt/page.mdx` | Nuxt integration using @t3-oss/env-nuxt with automatic runtimeEnv configuration |
| `contents/recipes/page.mdx` | Common recipes: boolean coercion, number parsing, enums, and other transform patterns |
| `contents/standard-schema/page.mdx` | Standard Schema support — use Zod, Valibot, ArkType, Typia, or any compliant validator |
