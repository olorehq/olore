# t3-env Documentation Structure

## Files

| File | Description |
|------|-------------|
| `contents/introduction/page.mdx` | Introduction to T3 Env with features overview - type-safe environment variables, Standard Schema support, server/client separation, and framework agnostic design |
| `contents/core/page.mdx` | Framework agnostic core package setup and installation guide |
| `contents/nextjs/page.mdx` | Next.js integration with preconfigured settings for all Next.js runtimes |
| `contents/nuxt/page.mdx` | Nuxt integration with automatic runtimeEnv configuration |
| `contents/customization/page.mdx` | Customization options including skipping validation and extending presets |
| `contents/recipes/page.mdx` | Common use case recipes for booleans, numbers, and other transformations with Standard Schema validators |
| `contents/standard-schema/page.mdx` | Standard Schema specification support and compatible validator libraries (Zod, Valibot, ArkType, Typia) |
