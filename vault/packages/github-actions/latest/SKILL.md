# GitHub Actions Documentation

GitHub Actions lets you automate, customize, and execute software development workflows directly in your repository. Create CI/CD pipelines, automate issue management, deploy to cloud platforms, and more using YAML workflow files.

- Writing or debugging GitHub Actions workflow YAML files
