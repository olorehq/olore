# Finnhub Documentation Structure

## Files

| File | Description |
|------|-------------|
| `contents/endpoints/default-api.md` | Canonical endpoint catalog (OpenAPI-generated): HTTP method, URL path, and parameter list for all ~100 Finnhub REST API endpoints. Start here for any question about what endpoint exists or what parameters it accepts. |
| `contents/usage/python-readme.md` | Python SDK setup and quick-start examples: installation, client initialization, and per-endpoint method calls (e.g. `finnhub_client.stock_candles`, `finnhub_client.company_news`). |
| `contents/usage/python-examples.py` | Executable Python code reference covering 30+ endpoint calls across stocks, bonds, congressional trading, ESG, market status, earnings estimates, and more. Read as a code reference for concrete call signatures. |
