---
title: 'Qt / QtQuick'
description: 'A community-maintained Qt Quick runtime that draws Rive graphics in QML with the Rive Renderer.'
---

<Note>This is not a Rive owned or maintained project.</Note>

rive-qt-plugin adds a `RiveView` item to QML. It draws with the Rive Renderer, using the same graphics API as the Qt window: Metal, Direct3D 11 or 12, OpenGL, or Vulkan. It requires Qt 6.5 or later and runs on macOS, Windows, and Linux.
