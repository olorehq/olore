# biome Documentation

Biome is a fast toolchain for web projects — a formatter, linter, and more. It replaces Prettier and ESLint with a single tool. Supports JavaScript, TypeScript, JSX, TSX, JSON, JSONC, CSS, GraphQL, and HTML.

## When to use

Use this skill when the user asks about:
- Installing and configuring Biome (biome.json, biome.jsonc)
- Running the formatter or linter via CLI (`biome format`, `biome lint`, `biome check`)
- Specific lint rules (e.g., `noUnusedVariables`, `useConst`, `noConsole`)
- Migrating from ESLint or Prettier to Biome
- Editor integration (VS Code, Zed, JetBrains, Neovim)
- Import organization and code actions (assist)
- CI/CD integration and git hooks
- Language support (JS, TS, CSS, JSON, GraphQL, HTML)
- Biome plugins and custom rules
