# Conversion Leads Integration

Upload offline conversion data from your CRM back to Meta's Conversions API to optimize lead quality for Facebook/Instagram Lead Ads.

## Eligibility

- Active Facebook/Instagram Lead Ads
- 15-17 digit Meta Lead ID stored in your CRM
- Minimum **200 leads per month**
- Can upload data **at least daily**
- Target conversion stage occurs within **28 days** post-lead generation
- **1-40% conversion rate** for the optimized stage

## Implementation Timeline (~3-4 weeks)

| Phase | Duration | Description |
|---|---|---|
| CRM Connection | Prerequisite | Download leads automatically |
| Setup | <1 day | Create/select Meta Pixel for CRM events |
| Integration | 3-4 weeks | Connect CRM via Conversions API |
| Verification | 1-2 days | Data validation by Meta |
| Configure Funnel | <1 day | Set up sales stages |
| Learning Phase | 2-4 weeks | Model training period |

## Key Roles

- **Marketing/Sales** — project initiation, funnel definition, Ads Manager access
- **CRM Admin** — field management, custom flow creation
- **Developer** — manual integration build and validation

## How It Works

1. Lead submits form via Lead Ad
2. Lead data flows to your CRM with Meta Lead ID
3. As leads progress through your funnel, send stage updates via Conversions API
4. Meta optimizes ad delivery for leads most likely to convert to your target stage

Integrating your CRM and using the Conversion Leads performance goal yields higher quality leads optimized specifically for conversion.
