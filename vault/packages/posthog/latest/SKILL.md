## When to use

Use this skill when the user asks about:
- Installing or configuring PostHog SDKs (JavaScript, Python, Node, React, iOS, Android, Flutter, Go, Ruby, PHP, .NET, Java, Rust, and 20+ frameworks)
- Capturing events, identifying users, and setting person/group properties
- Creating and evaluating feature flags, remote config, local evaluation
- Running A/B tests and experiments with statistical analysis
- Setting up session replay, network recording, and privacy masking
- Error tracking, stack traces, and source map uploads
- AI/LLM observability, tracing generations, embeddings, and spans
- Product analytics: funnels, paths, retention, trends, cohorts
- Web analytics dashboard and conversion goals
- Data warehouse SQL queries and external data source connections
- CDP destinations and sources (100+ integrations)
- Surveys and user feedback collection
- PostHog REST API and HogQL/SQL queries
- Privacy compliance (GDPR, HIPAA, CCPA)
- Self-hosting PostHog
- Migrating from Google Analytics, Amplitude, Mixpanel, etc.
