# Interface overview

This product walkthrough shows how the editor is laid out: the left panel, where you generate with Create and Chat, and the right panel, where you change an image you already have. It covers where to set models, styles and generation settings, how to bring back the prompt and settings behind any image, and how generated images connect to the tools around them: background removal, erase area, vectorization, mockups, and video generation.
