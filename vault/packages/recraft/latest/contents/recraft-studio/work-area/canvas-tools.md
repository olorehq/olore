# Canvas tools

These tools are accessible from the **toolbar at the bottom of the canvas**:

## Shape (Rectangle / Ellipse / Line / Arrow)

Use for annotations, diagrams, or layout prototyping.

## Text

Add and format editable text layers using Google Fonts.

## Brush

Freehand tool with adjustable size. Useful for rough markup, masking, or collaborative notes. Adjust size with bracket keys **\[** and **]**.

## Comment

Use to leave comments for collaborators.
