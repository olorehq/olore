# Keyboard shortcuts

## Image creation and tools

* **Enter** – Recraft (generate image)
* **I** – Image (Raster)
* **⇧ I** – Image (Vector)
* **S** – Image set
* **T** – Text
* **F** – Frame
* **V** – Move
* **H** – Hand (move canvas)
* **B** – Brush
* **C** – Comment
* **⇧ C** – Toggle comments visibility
* **E** – Erase area

## Clipboard and object control

* **⌘ C** – Copy
* **⌘ ⇧ C** – Copy image to clipboard
* **⌘ V** – Paste
* **E** – Merge objects

## Undo/redo and zoom

* **⌘ Z** – Undo
* **⌘ Y** – Redo
* **0** – Zoom 100%
* **= / +** – Zoom in
* **-** – Zoom out

## Layer order and flipping

* **⌘ ]** – Bring forward
* **⌘ \[** – Send backward
* **⌘ ⌥ \[** – Send to back
* **⌘ ⌥ ]** – Bring to front
* **⇧ V** – Flip vertically
* **⇧ H** – Flip horizontally

## Brush and text adjustments

* **]** – Increase brush size
* **\[** – Decrease brush size
* **⌘ .** – Increase text size
* **⌘ ,** – Decrease text size

## Selection and interface

* **⌘ D** – Duplicate selection
* **\\** – Show/hide UI
* **1** – Move viewport to fit project
* **2** – Move viewport to fit selection
