# Projects

Projects are virtual spaces where you create, iterate, organize, and store Recraft images and designs. You can create multiple projects in Recraft, and each project contains an infinite canvas that allows you to generate content in all directions without boundaries.

To create a new project, go to [Projects](https://www.recraft.ai/projects) and select **Create new project**.

To delete a project, there are two options:

* From the Projects page, hover over the project you want to delete, click on the three dots that appear, select **Delete**, then click **Delete** again to confirm.
* From an open project, click the dropdown selector at the top center, select **Delete**, then click **Delete** again to confirm.

Note: Deleted projects cannot be recovered, but you can still access the images from a deleted project in [History](https://www.recraft.ai/docs/recraft-studio/history.md).

## Project cover image

A project’s cover image by default shows a thumbnail preview of that project’s canvas. This is a view of a part of canvas. To better visually organize your projects, you can right-click on any image within a project and select **Set as project cover image** to set it to the Project’s cover image.

Note: For projects created before July 2025:

* The project cover image uses one of the images from within the project.
* If you open a project where no cover image was manually set, the cover image will automatically change to a project canvas thumbnail preview. Otherwise, it will stay as one of the images from the project.

## Renaming a project

There are two ways to rename a project:

* From an open project, click the dropdown selector at the top center (the default name is "Untitled"), select **Rename**, type the new name, then click **Save**.
* From the Projects page, hover over the project you want to rename, click on the three dots that appear, select **Rename**, type the new name, then click **Save**.
