# Remix

Remix generates new versions of an image while keeping the overall concept intact. Each remix introduces slight differences in elements like character appearance, object position, or scene composition.

Remix does not use a prompt. Instead, it uses the visual content of the original image to generate alternatives, with a similarity slider controlling how closely each new version matches the original.

**How to use Remix**:

1. Select an existing image on the canvas.
2. In the right panel, click **Remix image** under the **Modify** group.

   ![Image](https://mintcdn.com/recraft/oI1pyhIw4EfMVXwr/images/image-39.png?fit=max\&auto=format\&n=oI1pyhIw4EfMVXwr\&q=85\&s=da8783c0d9d319851a447dbd2a4a281f)
3. **Adjust similarity to the original**\
   Use the slider at the top to control how closely the new image should match the original. **Select the model**\
   Under the *Model* section, choose the generation model.

* Here, **V4** is selected. **Choose a style**\
  In the *Style* section, you can apply a predefined style to the image.
* Currently, **No styles** is selected.

![Image](https://mintcdn.com/recraft/oI1pyhIw4EfMVXwr/images/image-40.png?fit=max\&auto=format\&n=oI1pyhIw4EfMVXwr\&q=85\&s=40fd2966835486a68e39d2ff2b189a31)

4. Click **Generate** to produce a set of new outputs based on the selected image.
