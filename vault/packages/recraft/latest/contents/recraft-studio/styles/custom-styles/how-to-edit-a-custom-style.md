# How to edit a custom style

Styles created in Recraft Studio can be edited and iterated on at any time.

Editing a style does not overwrite the original. Instead, it creates a new version based on the updates.

**How to edit a style**:

1. Select an image on the canvas.
2. Click the **Style button** to open the Styles panel.
3. At the top of the panel, click on the **My styles** tab. Select the style you want to modify, then click **Edit style**.
4. In the editor, you can:
   * Adjust the weight (influence) of each reference image
   * Upload new reference images
   * Modify the style-level prompt
5. Generate test images to preview the result.
6. Once satisfied, click **Save style**. You’ll be prompted to give the updated version a new name. This preserves the original style while saving the new version as a separate style.
