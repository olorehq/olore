# How to export an image

1. Select the image or images on the canvas.
2. Click the **Export** button in context panel.
3. Specify your image dimensions, format (PNG, JPG, TIFF, PDF SVG, or Lottie) and resolution.
4. Click the **Export** button.

You can also right-click the image and choose **Export as...** from the context menu. Vector images can be exported as SVG and PDF for scalable use.
