# How to generate an image

1. Create a new project, or go to [http://recraft.new](http://recraft.new).
2. In the left panel, open the **Create** tab. Describe your image in the prompt field, then click **Generate**. After a few seconds, the new image appears on the canvas in a bounding box. Looking for the conversational, agentic way to generate? That's the **Chat** tab.

### Image generation options

Use the controls in the Create tab to adjust how your image is generated:

* **Generation type:** Choose **Image** to generate a raster image. **Vector**, **Video**, **Mockup**, and **Image set** are also available as generation types, each with its own set of controls.
* **Model:** Choose which image model to use. Different models are optimized for different output types, such as raster images or vector graphics.
* **Style:** Browse curated styles or explore an infinite feed of AI-generated styles. Apply a predefined style or create your own using reference images.
* **References:** Add reference images to guide generation. Click an image on the canvas to select it, then click it again to surface an **"Add"** thumbnail in the Create panel — that's what attaches it as a reference. A single click only selects the image and opens its Selected object panel; it doesn't attach it automatically.
* **Ratio:** Set the aspect ratio of your image to control its dimensions and framing, such as square, landscape, or portrait.
* **Colors:** Apply a predefined or custom color palette to guide image generation.
* **Generation count:** Choose how many images to generate from a single prompt. Multiple images are generated as variations and appear together on the canvas.

Want to iterate on a result? Click any image to open its **Selected object** panel, then use **Reuse** to take it as-is or tweak it before regenerating.
