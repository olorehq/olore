# Selecting a style

To generate an image in a specific style, click the Style button in the prompt panel to open the Style library.

It has two tabs: **Explore** (all available styles, filterable by category and searchable by descriptive terms) and **My styles** (your recent, liked, and created styles). When applying a style, choose **Precise** or **Flexible** to control how closely the output follows it — see Styles overview for details.

To guide a generation without a saved style, attach reference images directly in the prompt panel instead.

Select and set your style, then click **Generate button** to see the results.

For more about styles, go to [Styles overview](https://www.recraft.ai/docs/recraft-studio/styles/overview.md).
