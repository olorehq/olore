# Using custom fonts

You can upload your own font files and use them inside Recraft when adding text. Custom fonts are particularly useful for brand typography, logo refinement, packaging mockups, marketing visuals, and consistent presentation design.

## How to upload a custom font

1. Select the **Text** tool.
2. Go to the Context panel on the right, locate **Typeface** and click the **upload icon**.
3. Select your font file (`.woff`, `.woff2`, `.ttf`, or `.otf`).
4. The font will appear in your font list.
5. Apply it to any text layer.

## Important notes

* Uploaded fonts are available within your workspace.
* If a font file does not include certain character sets (for example, Cyrillic characters), those characters will not render correctly.
* Ensure the font file contains all required glyphs for your language and use case.
