## **FAQ**

**Why do different models have different credit prices?**

Different models have different credit prices because each model has unique capabilities and API costs. More advanced or higher-quality models require more credits per use. For example, Nano Banana Pro 4K costs more credits than basic raster generation. The credit cost reflects the model’s complexity and external API pricing.

You can find more details about how credits work [here](https://www.recraft.ai/docs/plans-and-billing/credits.md).
