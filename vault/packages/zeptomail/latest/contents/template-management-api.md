# Template management APIs

This API allows you to perform CRUD - Create, Read, Update and Delete - operations on templates. The following pre-requisites are required before you use these APIs:

1. You should generate an OAuth token to authenticate your API calls. Follow the guide given [here](https://www.zoho.com/accounts/protocol/oauth.html) to generate the OAuth token.
2. In addition to this, you should also generate the template alias or template key to use templates. Follow the steps given below to do so:
1. Go to the desired Agent.
2. Navigate to the Templates tab.
3. You can either copy the template key or template alias.

![Template tab](https://www.zohowebstatic.com/sites/zweb/images/zeptomail/agent-change-template.png)

**Agent >> Templates tab >> Copy template key or template alias.**

You can use either the template key or the template alias, and not both.

The following APIs are available in ZeptoMail to perform the template operations :

##### [Add email template](https://www.zoho.com/zeptomail/help/api/add-template.html)

##### [Update email template](https://www.zoho.com/zeptomail/help/api/update-template.html)

##### [Fetch email template](https://www.zoho.com/zeptomail/help/api/get-template.html)

##### [List email template](https://www.zoho.com/zeptomail/help/api/list-template.html)

##### [Delete email template](https://www.zoho.com/zeptomail/help/api/delete-template.html)
