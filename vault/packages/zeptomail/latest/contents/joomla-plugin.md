# ZeptoMail plugin for Joomla!

Joomla! is an open-source content management system, using which you can create websites and online applications. The [ZeptoMail plugin](https://extensions.joomla.org/extension/contacts-and-feedback/email/zoho-zeptomail/) for Joomla! helps you send transactional emails for your business, directly from your Joomla! account. To ensure timely delivery of your emails, you should make sure that they are sent from authorized email servers. This plugin helps you send your transactional emails using any of the Agents in your ZeptoMail account.

## Pre-requisites

To use ZeptoMail plugin for Joomla!, you need the following :

- A [ZeptoMail account](https://zeptomail.zoho.com/) with your sending domain verified.
- Joomla! account of version 4.

## How to install ZeptoMail plugin for Joomla!

1. Login to your Joomla! account.
2. Navigate to **System** from left pane.
3. Click **Extensions** from Install menu.

![](https://www.zohowebstatic.com/sites/zweb/images/zeptomail/joomlasetup.png)
4. In the **Install from Web** tab, search for Zoho ZeptoMail.

![](https://www.zohowebstatic.com/sites/zweb/images/zeptomail/joomlainstall.png)
5. Click Install.
6. Confirm the selection by selecting the **Install** button again.

![](https://www.zohowebstatic.com/sites/zweb/images/zeptomail/joomlaconfirmm.png)

## Configuring the ZeptoMail plugin

Once installed, you will be able to view the plugin under Components section.

1. Under the ZeptoMail drop-down, select **Configure account**.
2. Fill in the configuration parameters given below :
   - Hosted region : The region in which your ZeptoMail account is hosted.
   - Send Mail Token : The Mail Token generated within the Agent, using which you wish to configure in Joomla!
   - From email address : The email address that will be used while sending your emails.
   - From name : The sender name that will be displayed over the emails sent from your Joomla account.

     ![](https://www.zohowebstatic.com/sites/zweb/images/zeptomail/joomlaconfigure.png)
3. Click Save.
4. Once configured correctly, you will be able to send emails.

## Sending the test email

You can check the functionality of the plugin by sending a test email.

1. Navigate to the **Components** section in the left pane.
2. Under ZeptoMail drop-down, select **Test Mail**.
3. Enter the following details :
   - To : Email Address of the recipient.
   - Mail Type : Choose HTML to use ZeptoMail to send your emails.
   - Subject : Subject of the email.
   - Content : The body of the email.

     ![](https://www.zohowebstatic.com/sites/zweb/images/zeptomail/joomlatestemail.png)
4. Click Send Mail. The test email will be sent.
