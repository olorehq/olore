# prettier Documentation Structure

## Files

| File | Description |
|------|-------------|
| `contents/api.md` | Programmatic JavaScript API: format, check, resolveConfig, getFileInfo and related functions. |
| `contents/browser.md` | Running the standalone (non-Node) Prettier build in browsers, with ES module and UMD usage. |
| `contents/ci.md` | Running Prettier in CI, including GitHub Actions autofix setup. |
| `contents/cli.md` | The `prettier` command: options, --check/--write, file patterns, exit codes and ignore handling. |
| `contents/comparison.md` | How Prettier differs from ESLint, TSLint and stylelint; formatting vs code-quality rules. |
| `contents/configuration.md` | Supported config file formats, precedence, overrides, and EditorConfig support. |
| `contents/editors.md` | Setting up Prettier in VS Code, Emacs, Sublime, Atom, and other editors. |
| `contents/for-enterprise.md` | Commercial support through the Tidelift subscription. |
| `contents/ignore.md` | Using .prettierignore and prettier-ignore comments for JS, JSX, HTML, CSS, Markdown, YAML and more. |
| `contents/index.md` | Overview of Prettier as an opinionated formatter and the languages it supports. |
| `contents/install.md` | Installing Prettier locally, creating config and ignore files, and running it. |
| `contents/integrating-with-linters.md` | Disabling conflicting linter style rules via eslint-config-prettier and similar configs. |
| `contents/option-philosophy.md` | Why Prettier has few options and will not add more. |
| `contents/options.md` | Reference for all formatting options such as printWidth, tabWidth, semi, singleQuote, trailingComma, and parser. |
| `contents/plugins.md` | Using, developing and testing plugins: languages, parsers, printers and options. |
| `contents/precommit.md` | Formatting staged files with lint-staged, husky, git-format-staged, or pre-commit. |
| `contents/rationale.md` | Reasoning behind formatting choices: strings, empty lines, JSX, comments, decorators and more. |
| `contents/related-projects.md` | Community integrations for ESLint, stylelint, editors, and other tooling. |
| `contents/sharing-configurations.md` | Creating, publishing and consuming shareable Prettier configs. |
| `contents/technical-details.md` | How the printer works: AST to intermediate representation, based on Wadler's algorithm. |
| `contents/vim.md` | Using Prettier in Vim via vim-prettier, Neoformat or ALE. |
| `contents/watching-files.md` | Running Prettier on file changes using onchange or similar watchers. |
| `contents/webstorm.md` | Using Prettier in WebStorm and other JetBrains IDEs, including format on save. |
| `contents/why-prettier.md` | Benefits of adopting Prettier: enforcing style, saving review time, and supporting many languages. |
