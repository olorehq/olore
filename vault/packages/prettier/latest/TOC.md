# prettier Documentation Structure

## Files

| File | Description |
|------|-------------|
| `contents/api.md` | Programmatic API for running Prettier from Node.js (format, check, formatWithCursor, etc.) |
| `contents/browser.md` | Running Prettier in the browser using the standalone version without Node.js |
| `contents/ci.md` | Setting up Prettier on CI via GitHub Actions and autofix workflows |
| `contents/cli.md` | CLI usage: options, flags, glob patterns, and running prettier from the command line |
| `contents/comparison.md` | How Prettier compares to linters (ESLint, TSLint, stylelint) and when to use each |
| `contents/configuration.md` | Configuration file formats and locations (.prettierrc, prettier.config.js, etc.) |
| `contents/editors.md` | Editor integrations for VS Code, Emacs, Vim, Helix, and other editors |
| `contents/for-enterprise.md` | Tidelift enterprise subscription support for Prettier |
| `contents/ignore.md` | Ignoring files with .prettierignore and ignoring code blocks with prettier-ignore comments |
| `contents/index.md` | Overview of Prettier: supported languages and what the formatter does |
| `contents/install.md` | Installation instructions for npm, yarn, pnpm, and bun |
| `contents/integrating-with-linters.md` | How to integrate Prettier with ESLint and other linters using eslint-config-prettier |
| `contents/option-philosophy.md` | Philosophy behind Prettier's minimal options and why new options are rarely added |
| `contents/options.md` | All formatting options: print width, tab width, semicolons, quotes, trailing commas, parsers, etc. |
| `contents/plugins.md` | Plugin system for adding new languages or formatting rules to Prettier |
| `contents/precommit.md` | Setting up pre-commit hooks with lint-staged, pretty-quick, or husky |
| `contents/rationale.md` | Rationale behind Prettier's formatting decisions (strings, empty lines, objects, etc.) |
| `contents/related-projects.md` | ESLint/stylelint integrations, forks, and ecosystem tools that work with Prettier |
| `contents/sharing-configurations.md` | Creating and publishing shareable Prettier configuration npm packages |
| `contents/technical-details.md` | Technical internals: AST printing algorithm based on Wadler's "A prettier printer" |
| `contents/vim.md` | Vim-specific setup guide for vim-prettier, Neoformat, and ALE |
| `contents/watching-files.md` | Watching files for changes and auto-formatting on save using onchange |
| `contents/webstorm.md` | WebStorm and JetBrains IDE integration for Prettier |
| `contents/why-prettier.md` | Motivation for using Prettier: enforcing style guides, helping newcomers, saving time |
