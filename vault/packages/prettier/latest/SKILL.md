## When to use

Use this skill when the user asks about:
- Formatting code with Prettier (CLI or programmatic API)
- Configuring Prettier options (printWidth, tabWidth, semi, quotes, trailingComma, etc.)
- Setting up Prettier with editors (VS Code, Vim, WebStorm, Emacs)
- Integrating Prettier with ESLint or other linters
- Writing or using Prettier plugins for custom languages
- Pre-commit hooks and CI setup for Prettier
- Ignoring files or code blocks from formatting
