<Note>This page describes Checkly CLI version 10 and later.</Note>

The `checkly switch` command switches between multiple Checkly accounts that you have access to with your current credentials. Useful when you need to manage monitoring across different organizations or environments.

<Accordion title="Prerequisites">
Before using `checkly switch`, ensure you have:

- Valid Checkly account authentication (run `npx checkly login` if needed)
- Access to multiple Checkly accounts (team memberships, client projects, etc.)

If you only have access to one account, the menu lists only that account.
</Accordion>

## Usage

The basic command displays available accounts and provides an interactive selection interface. It changes the default account: the one commands use from then on.

```bash Terminal
npx checkly switch [options]
```

| Option | Required | Description |
|--------|----------|-------------|
| `--account-id, -a` | - | The id of the account you want to switch to. |

Without a terminal to answer the menu, `checkly switch` lists the accounts instead:

- In CI and other runs without a terminal, it fails with the available accounts and the `--account-id` command to use.
- Under an AI agent, it prints a JSON line with the default account and the choices, so the agent can ask you which account to use.

<Note>While `CHECKLY_ACCOUNT_ID` is set, commands use that account instead of the default; `checkly switch` still changes the default and warns. See [Working with several accounts](/cli/authentication#working-with-several-accounts).</Note>


## Command Options

<ResponseField name="--account-id, -a" type="string">

The `switch` command asks you to select an account interactively by default. Use this option to switch accounts non-interactively by specifying the target account ID directly.

**Usage:**

```bash Terminal
npx checkly switch --account-id="a43....."
npx checkly switch -a="a43....."
```

## Troubleshooting

### Account Not Listed
If an expected account doesn't appear:
- Verify you have active access to that account
- Check that your user hasn't been removed from the account
- Try logging out and back in to refresh account permissions
