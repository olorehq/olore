Every API check, URL monitor, Browser check and Multistep check run can be sent as one span to a single OTLP endpoint that you configure on [Settings > Traces](https://app.checklyhq.com/settings/account/traces). Setup, the span schema and a collector recipe live on the OTLP page, the first link below.
