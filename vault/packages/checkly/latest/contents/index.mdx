# Checkly Documentation

Checkly is the active monitoring layer for engineers & agents. Detect downtime with Playwright-powered monitors defined in TypeScript running from global or internal locations. Communicate outages with custom alerts and status pages. Resolve errors with traces and AI root cause analysis for new failures.

## Set up Checkly in a project

Run this in your project directory. It installs the Checkly CLI and [Checkly Skills](/ai/skills), creates a `checkly.config.ts`, and copies a starter prompt for your coding agent:

```bash
npx checkly init
```

To install only the skills for Claude Code, Cursor, Codex, and other agents:

```bash
npx checkly skills install
```

```txt
Set up Checkly monitoring in this project.

1. Run `npx checkly init` in this project, installing the Checkly skill for this agent. Load the installed skill before writing monitoring code.
2. Inspect the project structure, existing tests, and endpoints. Create a small set of monitors as code that match this codebase: URL monitors for key pages, API checks for important endpoints, and Browser Checks or a Playwright Check Suite if a Playwright config exists. Start with the most critical flow, not full coverage.
3. Ask me for an alert email address or Slack channel and create at least one alert channel assigned to the checks. Do not use placeholder values.
4. Run `npx checkly test` and fix anything that fails. If I am not logged in, ask me to run `npx checkly login`.
5. Show me what you changed and stop for my confirmation before running `npx checkly deploy`.

Documentation index: https://www.checklyhq.com/docs/llms.txt (append .md to any docs URL for Markdown).
```
