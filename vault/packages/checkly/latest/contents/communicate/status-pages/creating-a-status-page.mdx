To set up a status page, select **New status page** on the [Status pages overview](https://app.checklyhq.com/status-pages).

1. Enter a name for your page. This name is used in the page header and in emails to subscribers.
2. Customize the subdomain slug for your page. Status pages use the domain `<slug>.checkly-status-page.com` by default. See [Custom domains](/communicate/status-pages/custom-domain) to use your own domain.
3. Add **components** for the parts of your product you want to report on. Use **Add group** to nest components under a shared heading, and drag to reorder. See [Components](/communicate/status-pages/overview#components).
4. Optionally set a logo, favicon, and theme. See [Customization](/communicate/status-pages/customization).
5. Click **Create status page**. You will see your page's details, and a link to the public version of the page below the title.

![Status page editor](/images/docs/images/status-pages-v3/status_page_v3_editor.png)

You can now share the link to your status page, and your users can subscribe to receive notifications when incidents are posted.

To open incidents automatically when checks fail, add an [automation rule](/communicate/status-pages/incidents#incident-automation).

<Tip>
You can restrict access to your status page so only authorized users can view it. See [Password Protection](/communicate/status-pages/password-protection) for details.
</Tip>
