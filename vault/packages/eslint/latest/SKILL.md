## When to use

Use this skill when the user asks about:
- Configuring ESLint (flat config, ignores, language options, plugins, parsers)
- What a specific built-in rule does, its options, or examples
- Writing custom rules, plugins, processors, parsers, or formatters
- ESLint CLI flags, Node.js API, or editor/CI integrations
- Migrating between ESLint versions or from eslintrc to flat config
