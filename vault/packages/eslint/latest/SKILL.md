- Configuring ESLint rules, flat config, and eslint.config.js
- Specific built-in rules (no-unused-vars, prefer-const, eqeqeq, etc.)
- Writing custom ESLint rules or plugins
- TypeScript/parser integration with ESLint
- CLI options and command-line usage

- Node.js programmatic API (ESLint class, Linter class)

- Shareable configs, processors, and formatters
