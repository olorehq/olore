# rclone Documentation

Rclone is a command line program to sync, copy, move, and manage files across 70+ cloud storage backends including S3, Google Drive, Azure Blob, Dropbox, OneDrive, SFTP, and more.

Use this skill when the user asks about:
- Syncing, copying, or moving files between cloud storage providers
