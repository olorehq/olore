# NativeWind Documentation

NativeWind allows you to use Tailwind CSS to style React Native components across all platforms. It uses CSS StyleSheet on web and StyleSheet.create for native, providing a consistent styling experience.

- Installing or setting up NativeWind in Expo, React Native, or Next.js
