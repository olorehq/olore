## When to use

Use this skill when the user asks about:
- Mantine React components (Button, Modal, Select, Input, Table, etc.)
- Mantine hooks (useDisclosure, useLocalStorage, useMediaQuery, etc.)
- Theming, dark mode, color schemes, MantineProvider
- Form management with @mantine/form and useForm
- Date/time pickers with @mantine/dates
- Charts with @mantine/charts
- Extensions: notifications, modals, spotlight, carousel, dropzone, tiptap
- Styling: CSS modules, CSS variables, style props, responsive styles
- Next.js, Vite, or other framework integration with Mantine
- Migration from Mantine v6/v7 to v8
