# AI agents

{/* canonical @statelyai/agent overview from external-docs/agent/docs/index.md */}

`@statelyai/agent` lets you author an AI agent as a typed XState state machine.
The machine decides which work is legal; the host executes model calls with the
provider or SDK you choose.

Version 2.0 is currently in alpha. APIs can change between releases, so pin an
exact version.

[Read the current `@statelyai/agent` docs](/docs/packages/agent).
