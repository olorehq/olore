You can destroy a group and all of its databases using the following command:

```bash
turso group destroy <group-name> [flags]
```

<Note>

On paid plans, a destroyed group and its databases can be restored for up to five
days — see
[Recover Deleted Databases](/features/recover-deleted-databases).

</Note>

## Flags

| Flag          | Description                                                      |
| ------------- | ---------------------------------------------------------------- |
| `-y`, `--yes` | Confirms destroying the group, with all locations and databases. |
