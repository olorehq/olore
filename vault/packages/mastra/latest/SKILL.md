# mastra Documentation

Mastra is a TypeScript AI application framework for building agents, workflows, RAG pipelines, and multi-agent systems. It supports tools, memory, MCP servers, voice, streaming, observability, and deployment.

## When to use

Use this skill when the user asks about:
- Creating or configuring Mastra agents and tools
- Defining and running workflows with control flow, suspension, or human-in-the-loop
- Memory, semantic recall, and working memory for agents
- RAG, embeddings, chunking, and vector databases
- MCP server creation and tool registration
- Streaming agent or workflow output
- Voice (TTS, STT, speech-to-speech) in agents
- Authentication and server middleware
- Observability, tracing, and evaluation
- Deployment to cloud providers, Inngest, or custom servers
