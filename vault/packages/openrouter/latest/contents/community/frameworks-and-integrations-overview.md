# Frameworks and Integrations Overview

> Using OpenRouter with Popular Frameworks and Integrations

OpenRouter integrates seamlessly with popular AI frameworks and SDKs. Choose your preferred framework below for detailed integration guides:

## Available Framework Integrations

* **[Effect AI SDK](https://openrouter.ai/docs/guides/community/effect-ai-sdk.md)** - Integration with TypeScript Effect applications using the Effect AI SDK
* **[LangChain](https://openrouter.ai/docs/guides/community/langchain.md)** - Integration with LangChain for Python and JavaScript applications
* **[LlamaIndex](https://developers.llamaindex.ai/python/framework-api-reference/llms/openrouter/)** - Integration with LlamaIndex for Python and TypeScript RAG applications
* **[Mastra](https://openrouter.ai/docs/guides/community/mastra.md)** - Unified interface for AI model access through Mastra framework
* **[OpenAI SDK](https://openrouter.ai/docs/guides/community/openai-sdk.md)** - Direct integration using the official OpenAI SDK for Python and TypeScript
* **[PydanticAI](https://openrouter.ai/docs/guides/community/pydantic-ai.md)** - High-level interface for Python applications using PydanticAI
* **[TanStack AI](https://openrouter.ai/docs/guides/community/tanstack-ai.md)** - Integration with TanStack AI for React, Solid, and Preact applications
* **[Vercel AI SDK](https://openrouter.ai/docs/guides/community/vercel-ai-sdk.md)** - Integration with Next.js applications using the Vercel AI SDK
