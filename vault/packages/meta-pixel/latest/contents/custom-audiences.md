# Custom Audiences from Meta Pixel

Create custom audiences to segment website visitors into groups based on their actions for targeted advertising campaigns.

## Requirements

- Meta Pixel base code installed and tracking events
- Standard events, custom events, or custom conversions configured
- Facebook Ads Manager access

## Creating Audiences from Events

1. Go to **Events Manager** in Ads Manager
2. Select **Custom Audiences**
3. Choose the events or custom conversions to base your audience on
4. Configure audience rules (time windows, frequency, etc.)

Events Manager must be tracking your events or custom conversions correctly. Otherwise you will not be able to select them when setting up a custom audience.

## Creating Audiences from Custom Conversions

1. Navigate to custom conversion configuration
2. Select **"People who visited specific webpages"**
3. Apply the same URL criteria used when defining the original custom conversion
4. Save and activate the audience

## Audience Strategies

- **All website visitors** — broad retargeting
- **Visitors by page** — target people who viewed specific products or categories
- **Visitors by event** — target people who completed specific actions (e.g., AddToCart but not Purchase)
- **Time-based** — target visitors from the last 7, 14, 30, or 180 days
- **Frequency-based** — target repeat visitors or high-engagement users
